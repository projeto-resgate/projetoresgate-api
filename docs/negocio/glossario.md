# Glossário

Termos usados pela ONG e como aparecem no sistema. Quando o nome da ONG é diferente do nome do sistema, os
dois estão indicados.

| Termo (como a ONG fala)       | Significado                                                                                         | No sistema |
|-------------------------------|-----------------------------------------------------------------------------------------------------|------------|
| **Aluno**                     | Criança, adolescente (ou adulto, em formações para pais) atendido pelo projeto                       | Educando / Learner |
| **Responsável**               | Pessoa que responde pelo aluno; pode ser responsável pela **comunicação** e/ou **financeiro**        | Responsável |
| **Grupo familiar**            | Família do aluno: quem mora junto, renda e gastos                                                    | Grupo familiar |
| **Formação**                  | Atividade educativa com data, horário e voluntários (ex.: "Formação de Valores — 7º ano")            | Turma (Class Group) |
| **Programa**                  | Tipo de formação/iniciativa; define quais **funções de voluntário** existem                          | Programa |
| **Matrícula**                 | Inscrição do aluno em **uma formação**. Cada formação gera uma nova matrícula                        | Vínculo aluno–turma |
| **Equipe**                    | Subgrupo dentro de uma formação (uma formação pode ter várias)                                       | ❓ ainda não existe |
| **Tutor / Professor voluntário** | Voluntário que conduz a formação                                                                  | Colaborador (voluntário) |
| **Voluntário**                | Pessoa que atua sem remuneração; pode vir de uma empresa                                             | Colaborador |
| **Mentor**                    | Voluntário que acompanha alunos (aparece nas anotações de indicadores)                               | ❓ a confirmar se é papel próprio |
| **Secretaria**                | Quem cadastra alunos, controla materiais, presença e vale-transporte                                 | (perfil ainda não existe) |
| **Unidade**                   | Local físico do projeto, onde fica o estoque e se retiram os livros                                  | — |
| **Instituição / Escola**      | Escola ou empresa parceira                                                                           | Pessoa jurídica |
| **Série / Fase escolar**      | Série do aluno (ex.: 7º ano); cada formação tem uma fase sugerida                                    | Série escolar |
| **Ano letivo**                | Ano de referência do cadastro/recadastro                                                             | Ano letivo |
| **Recadastro**                | Atualização anual dos dados do aluno e da família                                                    | — |
| **IHE** (Índice de Hipossuficiência Econômica) | Nota de **0 a 1** da vulnerabilidade econômica da família, comparada às demais (1 = mais vulnerável). Antes chamado de "índice de carência" | ⬜ ainda não existe |
| **Renda líquida per capita (RLPC)** | (Renda − despesas com educação, habitação e saúde) ÷ moradores                                  | Renda per capita |
| **RLT**                       | Renda familiar total                                                                                 | Renda familiar |
| **Min–Max (normalização)**    | Transforma um valor em nota de 0 a 1 comparando com o menor e o maior da base                        | — |
| **Faixa de 20%**              | Cada quinto do ranking de carência; define o desconto da vaquinha (100%, 80%, 60%, 20%, 0%)          | ⬜ |
| **Parâmetros gerais**         | Valores definidos pela Administração: total da vaquinha e total para transporte                      | ⬜ |
| **Vale-transporte (VT)**      | Auxílio de transporte, **distribuído em proporção ao IHE**, com assinatura na retirada               | ⬜ |
| **Vaquinha**                  | Contribuição da família para ajudar a comprar os materiais, **com desconto por faixa de carência**   | ⬜ |
| **Boleto da vaquinha**        | Cobrança da vaquinha; o sistema marca se **já foi gerado** (isso congela o valor da pessoa)          | ⬜ |
| **Livros**                    | Material retirado pelo aluno **na unidade**                                                          | ⬜ |
| **Apostilas**                 | Material entregue **na escola** do aluno                                                             | ⬜ |
| **Editoras parceiras**        | Fornecem os materiais que faltam no estoque                                                          | Empresa/fornecedor |
| **Bolsista (APE)**            | Condição de bolsa do aluno; a sigla **APE** precisa ser confirmada                                   | Condição de bolsa ❓ |
| **Lista de presença**         | Folha assinada pelos alunos em cada aula                                                             | ⬜ |
| **Feedback**                  | Formulário de avaliação enviado aos pais ao fim do semestre                                          | ⬜ |
| **Desistência / Desligamento**| Aluno que sai do projeto, **com motivo**                                                             | Desistência |
| **Reativação / Retorno**      | Aluno que volta depois de desistir; pode voltar já a uma turma indicada                              | Reativação |
| **Cursando**                  | Aluno ativo com pelo menos uma turma **em andamento hoje**                                           | — |
| **Sem turma**                 | Aluno ativo no projeto, mas sem turma em andamento hoje (pausado, entre turmas ou aguardando)        | — |
| **Renovação**                 | Direito de receber materiais de novo no ano seguinte; exige participação nas formações               | ⬜ |
| **Drive interno**             | Espaço do próprio sistema para guardar documentos do aluno, termos e a documentação do projeto          | ⬜ |
| **Termo de compromisso**      | Documento assinado pelo aluno/família ao entrar                                                      | ⬜ |
| **Autorização de imagem**     | Termo para uso de imagem do aluno                                                                    | ⬜ |
| **EVN (Escola Via Net)**      | Sistema externo usado hoje para registrar alunos e turmas                                            | Sistema a migrar |
| **Access**                    | Banco de dados local usado hoje (cálculo do índice, materiais entregues)                             | Sistema a migrar |
| **DoeFácil**                  | Plataforma de doações usada pelo financeiro                                                          | Integração futura |
